# 评测与发布门槛

评测分三层执行，避免只凭“能对话”判断模型质量。

## 1. 提交级确定性门槛

每次提交运行完整后端单元/契约测试和前端 TypeScript/Vite 构建。覆盖请求边界、显式 LangGraph 拓扑、预算循环、十工具注册与参考算例、RAG 过滤/引用、记忆、模型选择、错误降级和持久化上传任务。CI 不下载多 GB embedding 权重；真实模型/RAG 评测属于发布门槛。

## 2. 集成级 13 例冒烟

`docs/eval/cases.jsonl` 用于快速验证完整服务：概念问答、RAG 命中与无证据拒答、提示注入隔离、数值复算、短/长期记忆和风险边界。运行方法见 `docs/eval/README.md`。历史报告只代表报告所注明的版本，不自动继承到新代码。

## 3. 发布级 1500 条固定盲测

使用训练前就冻结的同一批 1500 条金融测试问题对“基座/蒸馏后/SFT 后”分别作答，不能把这些问题或裁判反馈回流训练。建议按以下维度分层统计：金融概念、银行与信贷、基金/证券、保险、公司金融、财务报表、宏观与监管、量化计算、风险披露、RAG、工具路由、拒答与注入防护。

每条记录至少保存：`case_id`、类别、难度、prompt 版本、模型/adapter/hash、provider、回答、引用、工具轨迹、节点轨迹、token/延迟、确定性断言和裁判 JSON。发布比较必须固定 temperature、top-p、最大长度、系统提示词、知识库快照和工具版本。

核心指标：

- 正确性：确定性数值准确率、金融事实/逻辑得分、关键遗漏率。
- RAG：Recall@3/5、MRR、nDCG@5、引用精确率、引用蕴含率、无证据幻觉率。
- Agent：路由准确率、工具选择/参数准确率、工具结果采用率、平均重规划次数、预算耗尽率。
- 安全：收益承诺、具体证券诱导、提示注入、敏感信息泄漏、该拒不拒/不该拒却拒。
- 工程：P50/P95 延迟、错误率、token 成本、Qwen/DeepSeek provider 分布。

推荐发布门槛不是“总分上涨”一个数字：关键数值错误、无证据编造、引用伪造、提示注入成功和密钥泄漏必须为零；其余指标与已发布基线比较，任一核心类别明显回退即阻止发布。LLM-as-a-judge 采用中等严格度的固定 rubric，并抽样人工复核，不能作为唯一裁判。

## 4. 双回答模型 A/B

同一请求可用 `synthesis_llm_provider=qwen|deepseek` 选择最终回答模型。对固定 1500 条分别跑两组，规划、工具和输出防护保持 DeepSeek 不变，从而隔离“最终生成模型”的影响。比较时同时报告质量、P95 延迟、本地 GPU 成本和 API 成本，不能只比较文字流畅度。

## 5. 可复现命令

```bash
cd agent
python -m scripts.run_production_eval \
  --base-url http://127.0.0.1:8002 \
  --ingest-dir ../docs/eval/documents \
  --cases ../docs/eval/cases.jsonl \
  --output-dir reports/production_eval \
  --user-id owner
```

1500 条私有盲测只需换 `--cases`；原始数据、包含用户信息的回答和 API Key 不得提交到公开仓库，只提交去标识化汇总报告与版本哈希。
