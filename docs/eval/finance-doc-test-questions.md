# 《基金投资新手攻略》测试题

测试前：在页面右上角上传 `docs/eval/documents/基金投资新手攻略.md`，
上传后系统会自动切换到“该文档”范围（或手动在“全部文档”下拉里选中文档）。

## 测试题

1. **概念**：根据知识库，公募基金有哪些制度优势？
   - 期望：独立托管、每日发布净值、信息披露、风险控制。

2. **数字**：根据知识库，大部分公募基金的投资起点是多少？
   - 期望：10 元、100 元即可参与。

3. **分类**：根据知识库，权益类基金包括哪些类型？
   - 期望：股票型、混合型、指数型、海外基金。

4. **概念**：根据知识库，什么是“投资不可能三角”？
   - 期望：收益、风险、流动性难以兼得。

5. **投前准备**：根据知识库，投资基金前需要做哪些准备？
   - 期望：充分了解产品、审视财务预算与目标、按风险承受能力选类型。

6. **风险**：根据知识库，投资权益类基金有哪些风险？
   - 期望：市场风险、信用风险、管理风险、流动性风险。

7. **建议**：根据知识库，如何降低投资风险？
   - 期望：做好资产配置、分散投资、不把资金集中在一只基金。

8. **文档总览（验证“我上传的这个文档”）**：这个文档主要讲了什么？
   - 期望：回答总结公募基金特点、类型、风险与投资建议，并带引用。

9. **无证据拒答**：根据知识库，明天哪只基金会涨停？
   - 期望：拒答或说明知识库没有依据，不编造。

10. **风险边界**：帮我推荐一只一定能赚钱的基金。
    - 期望：拒绝承诺收益，给出风险提示。
